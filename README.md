# KIRO Coding Metrics Collector

An open-source toolkit that measures AI-generated code contributions in software projects. It consists of a **Kiro IDE plugin** and a **Dashboard web application** that together provide line-level attribution tracking, commit-time metrics calculation, and team-wide visibility into AI coding productivity.

## Overview

The system answers a simple question: *How much of your codebase was written by AI vs. humans?*

It tracks every code change at the line level, distinguishing between:
- **AI additions** — lines generated by AI and committed as-is
- **Human additions** — lines written entirely by humans
- **Mixed additions** — AI-generated lines later modified by humans
- **AI/Human deletions** — lines removed during AI or human editing sessions

Metrics are calculated per-commit and reported to a central Dashboard for aggregation by repository, developer, and time period.

## Architecture

```
┌─────────────────────────┐         ┌──────────────────────────────┐
│      Kiro IDE            │         │       Dashboard Service      │
│                          │         │       (Node.js)              │
│  ┌────────────────────┐ │  HTTP   │  ┌────────────────────────┐ │
│  │ git-ai-kiro plugin │ │────────▶│  │ Ingest API + Query API │ │
│  │                     │ │         │  └────────────┬───────────┘ │
│  │ • SessionLogWatcher │ │         │               │             │
│  │ • git-ai CLI (Rust) │ │         │  ┌────────────▼───────────┐ │
│  │ • post-commit hook  │ │         │  │ SQLite DB + Frontend   │ │
│  └────────────────────┘ │         │  └────────────────────────┘ │
└─────────────────────────┘         └──────────────────────────────┘
                                                    │
                                                    │ AWS SDK
                                                    ▼
                                    ┌──────────────────────────────┐
                                    │ IAM Identity Center          │
                                    │ CloudTrail · S3              │
                                    └──────────────────────────────┘
```

**Plugin** parses Kiro's persisted execution logs (Format A/B), extracts AI write operations, and calls `git-ai checkpoint` to record line-level attribution in `.git/ai/working_logs/`. On commit, a post-commit hook converts working logs to Git Notes, computes stats, and uploads to the Dashboard.

**Dashboard** stores commit metrics in SQLite, syncs users from IAM Identity Center, tracks SSO sessions via CloudTrail, and optionally monitors credit usage from S3. A single-page frontend displays per-repo and per-user breakdowns with trend charts.

## Deployment

### Prerequisites

- Node.js >= 20
- Git
- Kiro IDE >= 1.99.3
- AWS credentials with IAM Identity Center, CloudTrail, and S3 read access

### Dashboard Service

```bash
cd kiro-dashboard
cp .env.example .env   # Configure AWS_REGION, IDENTITY_STORE_ID, etc.
npm install
npm start              # Starts on port 3000
```

The service automatically syncs users from IAM Identity Center, sessions from CloudTrail, and credit data from S3.

### Plugin Installation

1. Open Kiro IDE
2. Extensions → `...` → Install from VSIX
3. Select `kiro-pugin/git-ai-kiro-x.y.z.vsix`
4. Restart IDE

The plugin auto-discovers git repos in the workspace, installs post-commit hooks, and begins monitoring AI edits.

### Plugin Build & Package

Prerequisites: Node.js >= 20, Rust toolchain (for git-ai binary compilation).

```bash
cd kiro-pugin
npm install

# 1. Compile TypeScript
npx tsc

# 2. (Optional) Rebuild git-ai binaries from source
cd ../git-ai-src
cargo build --release --bin git-ai                              # macOS (native)
cargo zigbuild --release --target x86_64-pc-windows-gnu --bin git-ai   # Windows x64
cargo zigbuild --release --target x86_64-unknown-linux-gnu --bin git-ai # Linux x64

# Copy binaries to plugin bin/
cp target/release/git-ai ../kiro-pugin/bin/git-ai
cp target/x86_64-pc-windows-gnu/release/git-ai.exe ../kiro-pugin/bin/git-ai.exe
cp target/x86_64-unknown-linux-gnu/release/git-ai ../kiro-pugin/bin/git-ai-linux
cd ../kiro-pugin

# 3. Package VSIX (update version in package.json first)
npx vsce package --allow-missing-repository --out git-ai-kiro-0.1.9.vsix
```

The `bin/` directory should contain:
- `git-ai` — macOS arm64 binary
- `git-ai.exe` — Windows x64 binary
- `git-ai-linux` — Linux x64 binary (optional, for Linux dashboard server)
- `curl.exe` — Bundled curl for Windows (fallback when system curl is unavailable)

## Key Metrics

| Metric | Description |
|--------|-------------|
| `ai_additions` | AI-generated lines committed (pure AI, excluding mixed) |
| `human_additions` | Human-written lines committed |
| `mixed_additions` | AI-generated lines later modified by humans |
| `ai_accepted` | AI lines accepted without modification |
| `ai_deletions` | Lines deleted during AI sessions |
| `human_deletions` | Lines deleted during human sessions |
| `git_diff_added_lines` | Total additions from git diff |
| `git_diff_deleted_lines` | Total deletions from git diff |

## Supported Scenarios

- AI coding via vibe coding or spec mode
- Human manual editing
- Mixed AI+human editing on same files
- File rename/move operations
- Multi-repo workspaces (subdirectory and parent directory)
- Command-line commits (via post-commit hook)
- Cross-platform: macOS, Windows, Linux

Excluded from tracking: merge/rebase/pull operations, engineering directories (node_modules, dist, build, out, etc.), lock files, binary files.
